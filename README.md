# Duisternis Tap

## How do I install these formulae?

`brew install duisternis/tap/<formula>`

Or `brew tap duisternis/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "duisternis/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
